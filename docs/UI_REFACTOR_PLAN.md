# Reset Agent UI/UX 重构计划：从“表单”到“沉浸式体验”

> **"好的设计不是没有可以加的东西了，而是没有可以减的东西了。"**

如果你想让应用具有**令人无法拒绝的吸引力**，让人一眼看到就觉得“哇，这东西懂我，它很高级，我想试试”，我们需要对视觉语言和交互逻辑进行彻底的降维打击式的重构。

## 🎨 目标视觉风格：Vercel / Linear 级别的黑客美学

我们要追求的是一种极致的、高级的、能让人瞬间安静下来的**暗色模式（Dark Mode）**体验。

### 核心设计原则
1. **极夜暗黑（Deep Dark）**：背景不再是毫无生气的浅灰，而是深邃的黑（如 `#050505`）。搭配极其微弱的局部发光效果（Emerald 绿或 Purple 紫），营造出深夜骇客的沉浸感。
2. **渐进式展开（Progressive Disclosure）**：绝不把所有东西堆在同一屏！用户同一时间**只能看到，且只需要关注一件事情**。
3. **毛玻璃与光感（Glassmorphism & Glow）**：卡片不再是生硬的实线边框，而是带有微妙半透明模糊效果的毛玻璃，以及悬浮时淡淡的光晕边缘。
4. **微动效（Micro-animations）**：所有的状态切换都必须如丝般顺滑。按钮点击有物理反馈，倒计时有平缓的呼吸动画。

## 🛠️ 改造方案详解

### 1. 交互流程重构：沉浸式 Wizard
将“一览无余”的平铺页面改为“一步一景”的专注流向导。

- **Step 1: 情绪捕获** 
  - 屏幕中央只有一句巨大的字：“**你现在感觉怎么样？**”
  - 下方悬浮 5 个极简的玻璃质感大卡片（带 emoji 和单字）。鼠标悬停时卡片微微上浮并发出微光。
- **Step 2: 痛点倾诉**
  - 选择状态后，其他卡片淡出，屏幕中央平滑过渡出一个巨大的、无边框的、只有底部发光线的输入框：“**把卡住你的东西写下来。**”
  - 回车直接提交。
- **Step 3: 呼吸与倒计时（核心体验）**
  - 屏幕清空。正中间出现一个巨大的呼吸光环（Breathing Ring）。
  - **动画**：光环随着“吸气...呼气...”的节奏放大缩小，强迫用户跟着它的节奏深呼吸。
  - 下方以打字机效果逐字显示 AI 生成的“最小下一步”。
- **Step 4: Agent 交接**
  - 倒计时结束，光环化作背景。
  - 优雅地滑出代码块风格的 Prompt 容器，带有一个极其有质感的“Copy”按钮。

### 2. 视觉元素重构 (CSS 层面)

#### A. 暗黑先锋调色板
```css
:root {
  --bg-deep: #050505;
  --surface-glass: rgba(20, 20, 20, 0.4);
  --border-glow: rgba(255, 255, 255, 0.08);
  --neon-emerald: #10B981;
  --text-main: #EDEDED;
  --text-muted: #888888;
}
```

#### B. 引入毛玻璃与发光特效
不再使用呆板的实线边框，全面采用 `backdrop-filter` 实现玻璃拟物化。
```css
.premium-card {
  background: var(--surface-glass);
  backdrop-filter: blur(16px);
  border: 1px solid var(--border-glow);
  border-radius: 20px;
  box-shadow: 0 4px 30px rgba(0, 0, 0, 0.5);
  transition: all 0.4s cubic-bezier(0.16, 1, 0.3, 1);
}
.premium-card:hover {
  transform: translateY(-8px) scale(1.02);
  border-color: rgba(16, 185, 129, 0.3);
  box-shadow: 0 10px 40px rgba(0, 0, 0, 0.4);
}
```

#### C. 字体排版升级
- 引入现代无衬线字体 **Inter**。
- 加大标题字号，缩减字间距（`letter-spacing: -0.04em;`），打造现代感。

### 3. 删除多余的认知负担
为了极致的美感和专注度，**已经**砍掉以下功能：
- ❌ 删掉“硬扛冲动”和“清晰度”的滑动条。
- ❌ 删掉一开始就暴露在外的“生成协议”等按钮，使用事件流自然触发状态。
