Reset Agent

开发者的 3 分钟恢复协议：判断继续、休息，还是把任务交给 Agent。

!
越疲劳，越硬扛；越硬扛，越发散。 Reset Agent 把状态恢复、任务重启和 Agent 交接合成一个可执行流程。
#AIAgent #开发者状态 #健康交付 #AgentHandoff

核心流程

NOT A TIMER, A RESET PROTOCOL
1 识别状态 疲劳、焦虑、卡住、困倦、疼痛
2 诊断卡点 用 LLM 把混乱描述压缩成判断
3 3 分钟 Reset 身体恢复 + 任务重启 + 最小下一步
4 交给 Agent 生成可复制的 Handoff Prompt
